最小下载集

本地已有文件，无须重下载。首批建议每块板只取「SoC 数据手册 + 原理图 + 板级档案/引脚表 + 上板文档 + 一份实测经验」。先做小样本解析和检索验收，再扩展子系统手册。

推荐阅读顺序

  1. 先看对应板卡档案与数据手册，确认型号、版本和当前实物。
  2. 再看原理图、Pinout/硬件总结，建立板级事实。
  3. 接着读上板与恢复、SDK 入门，区分资料说明与实机验证。
  4. 最后读开发经验及 ISP/NPU/媒体等专题，保留失败与不确定结论。

缺失或风险项

  • 源目录仅只读盘点，未逐页审完全部 PDF、未做全量 SHA256/许可核验；本清单是审核候选，不是可直接公开发布的名单。
  • RV1106 的开发经验、上板说明与上游 AIChat 文档可能含账号、网络或密钥线索；必须脱敏和人工审核。Echo-Mate 硬件与代码许可不同，Rockchip/Luckfox PDF 也需分别确认可存储与展示的授权范围。
  • 排除 .git、._*、构建 out、logs、tmp、captures 原始日志、SDK 整树、二进制模型、镜像、安装工具、压缩包和第三方依赖。必要时只存来源/哈希/下载入口。
  • 不要混用 RV1126B-P GPIO 手册、旧 RV1126/RV1109 设计指南、RK3588 图纸、8723BU 图纸或 IMX415 其他模组规格。RKNN 仓库的 RV1106/RV1103 Quick Start 不属于 RV1126B 首批资料。
  • PDF 图纸、DWG/STEP、摄像头/显示器件资料需要专门解析和板卡匹配；全文索引不可替代工程师审图。
