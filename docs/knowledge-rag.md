## 工作流

1. 管理员或开发者在 `/app/knowledge` 的六个分类中粘贴正文，或导入不超过 20 KB 的 `.md`/`.txt`；正文最多 6000 字。提交后是草稿，不参与检索。PDF/ZIP 尚未解析，既有板卡目录路径也不是已接入正文。
2. 管理员或开发者核对内容与来源后发布、退回或停用。发布保留版本、审核者、时间与 SHA256；旧已发布版本在草稿修改时保持有效，停用后退出新任务检索。草稿仅提交者可编辑。
3. 方案后台任务在调用模型前，仅从平台已发布正文和任务所属项目已发布正文检索。项目所有权在数据库检查；不会跨项目读取私有资料。采用限量关键词/中文二字词片段检索，不是向量嵌入检索。最多 5 份参考、约 6000 字正文、单个任务串行处理。
4. 模型提示词将片段作为不可信数据；服务端附加检索记录，不接受模型自称的引用。方案页面及 Markdown 下载显示参考资料的范围、来源、版本和摘要；无匹配会明确提示使用内置工程规则与模型通用知识。旧方案没有检索记录，界面不会伪称它做过检索。

检索命中只说明资料被送入本次生成上下文，不保证模型逐项采用，也不代表 BOM、引脚或电气参数已验证。`/app/knowledge` 仍仅允许管理员/开发者访问；普通用户可以生成方案，后台只读取已发布的共享资料及自己的项目资料。
