- 入口/标题/手机导航统一为「知识库」，地址 `/app/knowledge`；旧 `/app/board-library` 重定向到此处，目标页继续逐请求校验最新角色。
- 六类：开发板选型库、芯片手册、原理图库、PCB 库、驱动与示例、开发经验。已有开发板目录保留筛选/对比/看板；其他类别按名称、文件名、原目录分组归类，不代表文件已解析或核验。无记录的类别仅显示「暂无目录记录」。

- 本轮全量 154 测试通过，10 旧 DB 用例跳过；类型/ESLint/生产构建/静态包数据样本检查通过。临时内存账号 HTML/RSC 的新地址权限及旧地址跳转通过；实际开发者浏览器入口、六类导航、原理图搜索/详情、手机 390px 布局与空 PCB 分类通过，无控制台错误。无生产/数据库操作，未提交或上线。

以下为初版记录；最新入口与展示文案以上述调整为准。

## 任务确认与边界

- 后续 UI 调整已获用户确认：入口统一为「知识库」，新增六类导航、按现有目录分组展示，移除缺失资料状态提示。允许新增 `/app/knowledge` 和分类组件/测试；旧地址仅重定向，不变更服务端权限校验、原始目录数据或其他模块。

- 用户确认参照两张截图，将板卡目录集成到官网，仅管理员与开发者访问；先展示，后补原始资料。
- 允许范围：新增 `/app/board-library`、板卡目录数据与组件、侧栏/移动入口、帮助文案、测试和交接文档。
- 沿用已有会话签名与数据库角色，只为新页面增加服务端读取校验；不修改登录、账号角色、项目归属、审核、数据库结构、Runner 或部署脚本。
- 本轮不发布云端、不调用模型、不导入正式项目知识、不连接 OSS，不创建可用的下载/上传假入口。

## 数据与后续接入

目录来自用户提供的 `esp32s3-catalog/src/data/boards.json`。63 款板卡、12 类、18 个特性标签、1076 条资料记录（808 个文件路径、268 条无本地文件路径记录），均未上传或审核。剔除原目录的“已下载”状态、冗余统计，只保留名称/分类/原始尺寸/特性和资料名称/分组/路径；路径仅作来源线索，不生成文件链接。

这是平台级板卡目录展示，不是现有按项目发布的 Agent 知识库。所有参数待核验；原始尺寸字段含异常型号后缀，界面保留原始值并注明待核验。资料后续须增加私有存储、来源/版本/校验和、审核与受权下载，再决定如何关联项目并加入 Agent 检索；本轮不自动传给 Agent。

## 访问与验证

登录后通过「平台管理 → 板卡知识库」访问；手机通过顶栏「板卡库」访问。服务端逐请求读取最新账号角色；仅 `admin` / `developer` 返回目录。JSON 不放在 public，也不被客户端模块导入。未登录跳转登录页，其他角色仅收到无权限说明。客户端导航的角色过滤只是展示，不能代替服务端检查。
