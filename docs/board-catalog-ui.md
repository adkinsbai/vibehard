## 数据与后续接入

目录来自用户提供的 `esp32s3-catalog/src/data/boards.json`。63 款板卡、12 类、18 个特性标签、1076 条资料记录（808 个文件路径、268 条无本地文件路径记录），均未上传或审核。剔除原目录的“已下载”状态、冗余统计，只保留名称/分类/原始尺寸/特性和资料名称/分组/路径；路径仅作来源线索，不生成文件链接。

这是平台级板卡目录展示，不是现有按项目发布的 Agent 知识库。所有参数待核验；原始尺寸字段含异常型号后缀，界面保留原始值并注明待核验。资料后续须增加私有存储、来源/版本/校验和、审核与受权下载，再决定如何关联项目并加入 Agent 检索；本轮不自动传给 Agent。
