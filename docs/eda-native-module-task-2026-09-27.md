# EDA 原生模块样板链路任务确认

日期：2026-09-27。用户已要求在团队原生模块包尚未交付时，由平台侧自行制作一个最小 KiCad 模块并跑通链路。本文记录开发范围和验收边界，不是硬件设计审核结论。

首个样板为 3.3 V LED 指示电路：0603 电阻与 0603 LED 串联，暴露 VCC/GND 端口。它仅用于验证模块包、Agent 组合、原生文件和 PCB 链路，不代表实物电气参数、器件料号或制造可用性已经确认。模块包含原生单页 `.kicad_sch`、版本与文件哈希、端口映射和可编辑组合模板；运行时只向 Agent 提供受限模块元数据和稳定端口，不让模型伪造模块内部电路。

工程实现沿用现有 `EdaDocument`、受控编辑命令、KiCad 导出和 Agent 提案入口。新增模块插入命令需要确定性展开内部器件与网络；后续端口连接仍由现有 `connectPins` 执行。样板源码与组合模板必须通过真实 KiCad 网表比对；候选修改不得改变原工程。PCB 先完成原生板文件与 DRC 验证，自动布线另用真实 DSN/SES 往返验收。对模块结构的检查不能写成电气审核或 PCB 完工。

本任务不修改认证、租户权限、数据库迁移、生产部署和现有私有检索服务。交付时记录测试、KiCad CLI 版本、真实模型调用和云端验收分别是否完成。
