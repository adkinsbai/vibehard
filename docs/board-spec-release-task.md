# 板卡知识库页面：规格核验与发布任务确认

## 目标与边界

用户要求逐项核对 ESP32-S3 开发板目录中对外展示的硬件规格和资料归属，确认没有明显漏项、变体混用或虚假来源后，完成发布预检并上线新版知识库页面。本任务不改变知识正文、RAG 索引、OSS 原件、生产数据库、认证/角色逻辑、Runner 或设备服务。

允许修改：板卡目录的证据映射与展示数据、板卡知识库 UI、对应测试、只读核验脚本和文档。发布仅通过版本化 release 与既有发布/验证流程，不能直接改活跃 release 目录。若发现来源彼此矛盾或无法确定具体 SKU/PCB 版本，先标记或隐藏有争议的规格/资料，不得宣称已核验，也不得因此跳过发布预检。

## 核验门槛

1. 每款展示的板卡有明确的厂商型号页面；每条资料引用有 OSS 批次证据，并核对本地原件大小与 SHA-256。
2. 每项展示的硬件特性都有适用于该 SKU/PCB 版本的板级官方资料依据。区分板载器件、外接接口、可选配件、软件生态和芯片通用能力；不能把其他变体的原理图归到当前板卡。
3. 对全部展示板卡完成逐项复核；记录不确定项及处理，不把自动关键词命中当作验证结论。
4. 测试、类型检查、lint、生产构建、权限/保密检查和实际 release 的 `scripts/verify-frontend-release.mjs` 发布前后检查通过，并确认 Demo/PCB 资源没有回退。

## 当前资料核验结论

- 61 款展示候选的厂商产品/系列页面已定位；2 款没有可用 OSS 原件的旧目录条目拟不展示。
- 767 条展示候选引用均可在本地资料包找到，大小和 SHA-256 与已核对 OSS 批次快照完全一致；573 PDF、173 ZIP、18 7z、3 RAR；PDF/ZIP 元数据解析错误为 0。
- 19 条文件名经过变体复核后，5 条精确型号错配从页面关联中排除；4G 系列共用资料、1.54 触摸系列共用主板资料保留并加范围提示。61 款的旧硬件标签已被逐项映射为有依据的新标签或记录了删除原因，软件生态标签不再冒充硬件功能。展示的是 351 项有官方板级页面依据的特性标签；不包括整机引脚、电流、存储容量等未在此页面展示的参数，也不等于实物上板验收。
- 页面拟展示 61 款、762 条关联（568 直接索引、88 部分索引、106 仅原件）。原始证据快照仍保留 767 条引用，5 条仅在 UI 关联排除，不操作 OSS 或既有 RAG 索引。

这些记录证明当前页面展示的型号、硬件特性和原件关联有可追溯资料依据；无法确定的 SKU/版本信息不作为通用规格显示。

## 发布结果

2026-09-26 上线 `20260926-board-spec-v2`。本地 253 项测试通过、13 项独立数据库用例跳过；类型、定向 lint 与 `/vibehard` 生产构建通过。隔离候选、正式回环和公网均通过知识库权限/数据与 Demo/PCB 完整发布验证。首次 v1 候选因漏设构建 basePath 未通过预检、从未激活；v2 修复后才切换正式平台。版本包/回滚/受保护服务核验见 `docs/deployment-ldcx.md`。

## 已复核的型号/文件关联

- `ESP32-S3-LCD-1.9`：本地原理图图框写 `ESP32-S3-Touch-LCD-1.9`，含 TP 引脚；官方产品页明确目录型号是不带触摸的基础 SKU。不得在基础 SKU 详情中将此文件称为“对应板原理图”。
- `ESP32-S3-LCD-2`：原件图框写 `ESP32-S3-Touch-LCD-2`；同样不能直接作为基础 SKU 的板级电路依据。
- `ESP32-S3-LCD-2.8`：官方产品页明确 2.8 英寸电容触摸屏，触摸版命名的原理图与其功能一致；旧“LCD屏”分类应修正。
- `ESP32-S3-LCD-2.8C`：目录型号没有 Touch，原理图图框却写 `ESP32-S3-Touch-LCD-2.8C`；官方页面未明确基础 SKU 带触摸，应把该文件标为“触摸变体资料/需核版本”，不得把触摸能力自动写入基础款。
- `ESP32-S3-Touch-LCD-1.54`：官方说明 LCD 与 Touch-LCD 两 SKU 除触摸面板外其余相同；原理图图框为 `ESP32-S3-LCD-1.54`，含 TP 引脚，可作为系列共用主板设计来源，但触摸控制器仍须对应 Touch SKU 核对。
- 两款 4G 产品目录下的三个硬件文件哈希完全相同，是 `ESP32-S3-A-SIM7670X-4G` 系列资料。V2 原理图图中可见 A7670 电路；应按具体模块型号/板版本说明适用性，不能把系列名误当为具体模块证据。
- `ESP32-S3-ePaper-1.54` 与 `1.54G` 的原理图标为 `Touch-ePaper-1.54`，有触摸排线/信号。官方 1.54 页面还区分 V1/V2 与触摸/非触摸 SKU；暂仅视为系列电路参考，不证明每个 SKU 的触摸功能或完全同版布线。
