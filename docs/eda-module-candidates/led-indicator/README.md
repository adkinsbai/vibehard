# LED 指示模块候选：待硬件审核

`candidate.led-indicator@0.1.0` 是**独立的待审核原生包**，用于测试受控导入和待审目录。原理图、PCB 与库表从 `lib/eda/modules/sample-led` 软件样板复制后单独存放；原理图标题改为待审候选，并重新计算源文件 SHA-256。它**不是**从私有案例库提取的已审核模块，也未发布给用户或 Agent。

已知电路是一个 470 Ω 电阻串联一个 LED，暴露 VCC（清单暂列 3.0–3.6 V）和 GND 两端口。PCB 为两器件、单条内部走线的简化双层矩形设计块。KiCad 9.0.8 可以导出网表，端口网络与清单一致；软件导入器能保留受控器件、封装、内部网络与走线。这些仅说明**文件链路可处理**。

发布前必须由硬件工程师补齐并核对：LED 厂家/料号、最大连续电流、正向压降及温度范围；电阻厂家/料号、功率与容差；VCC 实际使用条件与最差组合电流/功耗计算；LED 极性和封装焊盘；PCB 铜宽、间距及工艺；与目标主板的接口和测试点；原件授权、签审报告及例外项。上述项目没有完成，不能称该候选为功能可靠或可制造的设计。

本目录的 `manifest.json` 使用 `pending-review`，无 `review` 字段。提交受控目录后仍只能处于 `pending`；只有名单内且不同于提交者的硬件审核账号，核对外部签审证据后才能执行发布。当前未配置审核名单，发布入口默认拒绝。
