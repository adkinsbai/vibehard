# EDA product design

Scope /eda and /app/eda. Professional desktop workspace, responsive drawers on small widths.
Warm-white schematic sheet on a quiet graphite shell; one restrained teal/green accent for selection/actions. Copper colors reserved for PCB layers. Compact system sans typography, mono for values/coordinates. 4/8px spacing rhythm. Toolbar 48px, header 52px, library ~210px, inspector/Agent ~300px, sheet takes remaining space. Minimal radii, visible focus, real canvas grid only. No decorative glow, hero section, fake progress, invented verification states.
Inspector and Agent share right panel tabs; diagnostics/history bottom panel. User selection highlights matching component across schematic and PCB. Empty/error/unconfigured states tell the truth. Editable data controls must work, not only pan and zoom.
